Each licensed version is delivered as:

- A source archive of the tagged version.
- An offline container image archive and its digest.
- The licence texts of the third-party components (also inside the image under `/usr/share/licenses/koldera`) and
  the [NOTICE](../../NOTICE) file.
- A list of SHA-256 checksums for the files above.

Delivery channel: [DELIVERY CHANNEL, e.g. access to a private repository or a download link]. Access ends when
maintenance ends; files already delivered stay with the licensee.

## What the software does not do

- No licence keys, activation or runtime licence checks.
- No telemetry and no connection to the licensor.
- No remote shutdown and no feature that stops working when maintenance ends.

The licensee is responsible for keeping delivered files confidential and within the licence scope
([LICENSE-SCOPE.md](LICENSE-SCOPE.md)).
