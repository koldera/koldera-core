# Fixtures

Every fixture in this repository is synthetic: written for these tests, with no customer document, no real
site content and no personal data. Reviewed 2026-10-05 (Info dictionary, first text, all text, link targets and
e-mail addresses read with `pdfinfo` / `pdftotext` / `pdftohtml`). Addresses and hosts are limited to
`example.com`, `example.org`, `*.example`, `*.invalid` and reserved/loopback ranges; the only public URL is the
W3C WCAG overview in `engine/src/test/resources/generated/generated-annual-report.pdf`.
`scripts/fixtures-listed.test.mjs` fails when a binary or document fixture under a test directory is not listed
here with its full path.

## PDFs built at test time (engine)

`engine/src/test/java/com/koldera/pdf/fixtures/SyntheticPdfFactory.java` and the `*Test` helpers that
call it build PDFs in memory with PDFBox (plain text pages, tagged and untagged variants, forms, images, signed,
encrypted and corrupt shells, non-embedded standard fonts, hostile structure trees, Cyrillic text, image-only scans, invisible OCR text). The text
is a fixed sentence such as "Synthetic fixture paragraph for accessibility engine tests." Nothing is read from
disk. `CorpusGeneratorTest` (skipped by default) writes a local, ignored corpus from the same factory.

## HTML (scanner)

| File | Content |
|---|---|
| `scanner/tests/fixtures/labelled.html` | "Newsletter" form with a labelled e-mail input and a 1x1 GIF with empty `alt`; the axe-core "no violation" case. |

`scanner/tests/fixtureServer.ts` serves them and a few generated routes (`/slow`, `/big`, `/many.html`,
`/redirect`, `/echo-headers`, `/ws-probe.html`, `/report`) on a loopback port for the duration of a test run.

## HTML, images and JSON inside test sources

`renderer/tests/*.test.ts` hold their HTML as string literals (articles, tables, lists, figures, SVGs, forms,
hostile markup for the preflight). Inline images are 1x1 base64 PNG/GIF literals. Requests and results are
object literals or small JSON strings with `jobId` `123e4567-e89b-42d3-a456-426614174000`. Hostile
URLs use `example.org`, `example.com`, `*.example` and `render.koldera.invalid`; the scanner's destination-policy
tests use loopback, link-local and private addresses.
